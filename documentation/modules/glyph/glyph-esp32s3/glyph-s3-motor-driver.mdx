## Integrated motor control

The TB6612FNG provides two direction-and-speed control channels. Set direction with the channel input pins and control speed with PWM. The driver also supports braking, coast, and standby modes. Since the driver is already on the board, a project does not need a separate G-Mod motor-driver module or its extra board-to-board wiring.

The TB6612FNG datasheet specifies a 2.5–13.5 V motor supply range and 1.2 A average output per channel. Its 3.2 A rating is for a single pulse; it is not a continuous current rating. Actual usable motor current depends on the motor, PCB cooling, operating conditions, and the driver's datasheet limits. [See Toshiba's TB6612FNG datasheet](https://toshiba.semicon-storage.com/info/datasheet_en_20141001.pdf?did=10660).

<Warning>
Choose a motor supply that matches the motors and remains within the TB6612FNG limits. Check motor stall current and wiring polarity before powering the board. Do not treat the driver's single-pulse peak current as a continuous rating.
</Warning>

## A compact platform for motion projects

This is a premium all-in-one option for projects that need a capable S3 controller and motor control on one board: small robots, differential-drive vehicles, pan-and-tilt mechanisms, and interactive moving builds. The ESP32-S3 module supports Wi-Fi and Bluetooth LE, so the same board can handle motor commands, sensor readings, and wireless control.

The design uses an ESP32-S3-MINI-1-N4R2 module. For its processor, memory, and wireless capabilities, see the [Espressif module datasheet](https://documentation.espressif.com/esp32-s3-mini-1_mini-1u_datasheet_en.html). For the rest of the Glyph S3 pin and power information, see the [Glyph S3 overview](/documentation/modules/glyph/glyph-esp32s3/glyph-s3-overview) and [pinouts](/documentation/modules/glyph/glyph-esp32s3/glyph-esp32-s3-pinouts).
