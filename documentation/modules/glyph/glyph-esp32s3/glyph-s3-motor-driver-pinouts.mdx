The pinout diagram shows the board labels and connector locations. The tables below list the nets and GPIO assignments from the board schematic.

### J1: 12-pin header

| Pin | Board label | ESP32-S3 / function |
| :--- | :--- | :--- |
| 1 | +BATT | Board battery/system rail |
| 2 | EN | Enable/reset |
| 3 | VBUS | USB 5 V input rail |
| 4 | D10 | GPIO10 |
| 5 | D9 | GPIO9 |
| 6 | D8 | GPIO8 |
| 7 | D7 | GPIO7 |
| 8 | D6 | GPIO6 |
| 9 | D2 | GPIO2 |
| 10 | D1 / BATT_MSR | GPIO1 / battery measurement |
| 11 | SDA | GPIO4 / I²C data |
| 12 | SCL | GPIO5 / I²C clock |

### Glink connector J5

| Pin | Signal |
| :--- | :--- |
| 1 | GND |
| 2 | +3.3 V |
| 3 | SDA / GPIO4 |
| 4 | SCL / GPIO5 |

J5 is the Qwiic/STEMMA QT-compatible Glink connector.

### Motor connectors

J7 and J8 are 2-pin Molex PicoBlade motor output connectors wired to the onboard TB6612FNG:

| Connector | Pin 1 | Pin 2 | Channel |
| :--- | :--- | :--- | :--- |
| J7 | AO_2 | AO_1 | Motor A |
| J8 | BO_2 | BO_1 | Motor B |

Connect one brushed DC motor across each pair. A bipolar stepper motor uses both output pairs for its two windings.

### Motor-driver control GPIOs

These ESP32-S3 GPIOs are connected internally to the TB6612FNG control inputs:

| TB6612FNG signal | ESP32-S3 GPIO | Function |
| :--- | :--- | :--- |
| PWMA | GPIO41 | Motor A speed (PWM) |
| AIN1 | GPIO39 | Motor A direction |
| AIN2 | GPIO38 | Motor A direction |
| STBY | GPIO42 | Driver standby/enable |
| PWMB | GPIO40 | Motor B speed (PWM) |
| BIN1 | GPIO47 | Motor B direction |
| BIN2 | GPIO48 | Motor B direction |

These pins are used by the onboard motor driver. Use the [motor power notes](/documentation/modules/glyph/glyph-esp32s3/glyph-s3-motor-driver-power-management) before wiring motors.

### Battery and USB-C

- **Battery connector J6:** Pin 1 GND; pin 2 Bat_PWR (battery positive).
- **USB-C connector J4:** USB power and native USB data/programming.

Use the [Power Management](/documentation/modules/glyph/glyph-esp32s3/glyph-s3-motor-driver-power-management) page for supply details and limits.
