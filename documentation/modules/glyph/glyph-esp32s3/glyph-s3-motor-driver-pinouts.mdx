The diagram shows the board-specific pin assignments and connector labels. Use it when wiring motors, power, and peripherals; this version includes the motor-driver connections as well as the ESP32-S3 pins.

### Motor outputs

The TB6612FNG exposes two output pairs:

- **AO_1 / AO_2**: Motor A output
- **BO_1 / BO_2**: Motor B output

Connect each brushed DC motor across one output pair. For one bipolar stepper motor, use both pairs as its two windings. Motor direction and PWM control use the ESP32-S3 connections marked in the pinout diagram.

### ESP32-S3 pins and peripherals

The board uses the ESP32-S3 pin functions shown in the diagram. Check the labels before assigning GPIOs in firmware, especially for pins already used by the onboard motor driver, USB, boot, or reset circuitry. For the general ESP32-S3 peripheral reference, see the [Glyph S3 pinouts](/documentation/modules/glyph/glyph-esp32s3/glyph-esp32-s3-pinouts).
