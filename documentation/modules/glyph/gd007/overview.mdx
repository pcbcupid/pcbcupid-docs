The Glyph RP2040 is a compact development board built around the Raspberry Pi RP2040 microcontroller, designed for projects that need a balance of GPIO flexibility, battery-powered operation, and a small footprint. It integrates a Li-Po battery charger, a low-quiescent-current 3.3V regulator, and a USB-C connector for programming and power, making it suitable for wearable, handheld, and sensor applications.

- **Dimensions:** 50.8 × 22.9 mm (2.0 × 0.9 in), 2.5 mm board thickness
- **Processor:** Raspberry Pi RP2040, dual-core Arm Cortex-M0+ at up to 133 MHz
- **RAM:** 264 KB SRAM
- **Flash:** 2 MB QSPI flash (onboard)
- **GPIO:** 28 pins broken out, including 3 analog inputs (GPIO26–28), 2 UARTs, 2 SPI, 2 I2C, and 4 PWM channels

### Connectivity

The board exposes all 30 GPIO pins of the RP2040 through two rows of through-hole pads (0.1" pitch) on the long edges, plus a 3-pin header for battery, enable, and VBUS. A USB-C connector provides both programming and power, with the USB data lines routed directly to the RP2040's native USB controller.

### Development Support

Programming is done over USB-C using the RP2040's built-in bootloader — hold the BOOT button (GPIO25) while plugging in to enter USB mass-storage mode, then drag-and-drop a UF2 firmware file. The board is fully supported by the Raspberry Pi Pico SDK, MicroPython, CircuitPython, and the Arduino core for RP2040.

### Memory and Storage

The RP2040's 264 KB SRAM is split into six independent banks, allowing flexible allocation between the two cores. The onboard 2 MB QSPI flash provides ample space for firmware, filesystems, or CircuitPython code, and supports memory-mapped execute-in-place (XIP) for fast code execution.

### Power Management Features

The Glyph integrates an MCP73831 Li-Po charge controller with a 4.2V termination voltage and a programmable charge current (set by an onboard resistor). A low-dropout regulator provides the 3.3V rail, and the L_EN pin allows external control of the regulator for low-power sleep states. The +BATT pin gives direct access to the battery for monitoring or alternative power routing.

### Bootloader and Programming

The RP2040's ROM bootloader is always available — no external programmer is required. For advanced debugging, the SWD (Serial Wire Debug) pins (GPIO24/GPIO25) are broken out, allowing connection to a debug probe for breakpoints and trace.

> **Note:** The battery charger is designed for single-cell Li-Po/Li-Ion batteries only. Do not connect other chemistries or multi-cell packs.
