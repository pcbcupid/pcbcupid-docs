Introducing the **Glyph S3 Lucid**, an interactive and versatile microcontroller development board powered by the high-performance ESP32-S3 chip. Designed for portable handheld gadgets, mini gaming devices, and interactive AIoT applications, the Glyph S3 Lucid comes equipped with an **integrated 0.91" LCD display**, **3 tactile SPST action buttons**, and an **inbuilt Battery Management System (BMS)** for comprehensive battery safety and regulation.

- **Dimensions**: Measures 50.8mm x 22.8mm x 1.6mm (without headers soldered)
- **Processor**: ESP32-S3 dual-core LX7 microprocessor @ 240 MHz, 3.3V logic and power
- **Memory**:
  - **SRAM**: 512 KB Internal SRAM
  - **PSRAM**: 2 MB Quad SPI PSRAM
  - **Flash Memory**: 4 MB SPI Flash
- **GPIO**: 20 GPIO pins with the following capabilities:
  - 9 GPIO pins support 12-bit ADC (ADC1): IO1, IO2, IO4, IO5, IO6, IO7, IO8, IO9, IO10
  - I2C
  - SPI
  - UART
  - USB Serial
- **Display**: Integrated 0.91" LCD display for visual feedback, graphics, and gameplay
- **3 SPST Action Buttons**: 3 tactile push buttons for game controls, menu navigation, and interactive input
- **Power Management & Inbuilt BMS**:
  - Inbuilt Battery Management System (BMS) with overcharge and overdischarge protection
  - USB Type-C connector for power, programming, and serial port debugging
  - 3.3V regulator with 900mA peak current output
  - Built-in LiPo / Li-ion charger with charging status indicator LED
  - Auto Switch between Battery & USB Power (hot-swap support)
  - Battery connection via onboard BAT and GND pins (with inbuilt BMS protection)
  - Ability to turn off the battery with the onboard slide switch
  - Reverse voltage protection with diode
- **Additional Features**:
  - **On-board Status LED**: Connected to **GPIO 33**
  - On-board GLINK connector for easy integration with QWIIC, STEMMA QT compatible sensors & modules
  - High-quality Reset and Bootloader buttons for easy access

### Native Bootloader and Programming

The Glyph S3 Lucid features a built-in USB bootloader that makes programming new firmware easy and keeps the cost of the board down. On first-time use, hold down the BOOT button while plugging it into USB, and it will appear as a COM PORT in your Device Manager. If you face any issues related to hardware detection on your system, please check out our troubleshooting guide [here](https://learn.pcbcupid.com/boards/needs/arduino-ide-setup#hardware-not-detecting).

### Interactive Display & Buttons

The Glyph S3 Lucid provides a complete, self-contained interactive interface:
- **Integrated 0.91" LCD Display**: Built directly onto the board for immediate visual output without needing external breadboards or extra wiring.
- **3 SPST Tactile Switches**: Three momentary switches integrated directly on the board to serve as user inputs (such as Left, Right, and Action / Select) for mini games, dashboards, and handheld UI controls.

### Connectivity

The Glyph S3 Lucid excels in connectivity with its built-in Wi-Fi and Bluetooth LE support. This makes it ideal for IoT and connected handheld applications where reliable wireless communication is crucial.

### Memory Architecture

The Glyph S3 Lucid features **512 KB of onboard SRAM**, **4 MB of SPI Flash**, and **2 MB of Quad SPI PSRAM**. The integrated 2MB PSRAM provides generous memory bandwidth and storage for display framebuffers, graphical assets, and complex data buffers.

### S3 Chip Features

- **Xtensa Dual-Core 32-bit LX7**: High-performance compute running up to 240 MHz with vector instructions for AI/ML acceleration.
- **BluFi**: Easy Bluetooth-assisted Wi-Fi provisioning.
- **RF Coexistence**: Simultaneous Wi-Fi and Bluetooth operation.
- **ESP-BLE-MESH & ESP-WIFI-MESH**: Scalable multi-device mesh networking.

You can read more about it in the [ESP32S3 DATASHEET](https://files.pcbcupid.com/Documentation/Boards/glyph-S3/PCBCUPID_esp32-s3_datasheet.pdf) and [ESP32S3 OFFICIAL](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/get-started/) documentation.
