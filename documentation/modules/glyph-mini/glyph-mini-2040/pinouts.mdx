The Glyph Mini 2040 has many pins, ports, and features. This page takes you on a tour on each of the pin on the board!

### Power Pins and Connections

- **GND**: This is the common ground for all power and logic.
- **USB**: This is the positive voltage to/from the USB C jack, if USB is connected (This is usual at voltage 5v).
- **RUN / RESET**: This is the run/reset pin of the RP2040, you can pull down this using an external button or other controller to reset the board.
- **3.3V**: These pins are the output from the 3.3V regulator, they can supply up to 800mA peak current.

### Communication Pins

#### I2C, SPI, and UART on RP2040

The RP2040 is capable of handling I2C, SPI, and UART on many pins. However, to simplify things we have assigned few of the IO pins to make things simpler for users.

#### I2C Pins

- I2C0 SCL: **SCL**, GPIO9
- I2C0 SDA: **SDA**, GPIO8

#### SPI Pins

- SPI0 SCK : **SCK**, GPIO2
- SPI0 MOSI: **MO**, GPIO3
- SPI0 MISO: **MI**, GPIO4
- SPI0 CS  : **SS / CS**, GPIO5 (or any available GPIO)

#### Buttons and Status LED

- **BOOT Button**: Hold down during power-on / reset to enter the UF2 bootloader mode (appears as a USB mass storage drive).
- **RESET Button**: Restarts the RP2040 microcontroller.
- **Status LED**: User-controllable status LED connected to GPIO16.

#### PWM Pins

The RP2040 supports PWM on all GPIO pins. There are 8 dual-channel PWM slices, each with configurable frequency and duty cycle. The important thing to know is that you cannot use the same channel on different pins at the same time. Please refer to [RP2040 DATASHEET](https://files.waveshare.com/upload/f/fd/Rp2040_datasheet.pdf).

### Analog Pins

The RP2040 has four 12-bit ADC channels. These pins are the only pins capable of handling analog, and they can also do digital.

- **A0/GPIO26**: ADC channel 0
- **A1/GPIO27**: ADC channel 1
- **A2/GPIO28**: ADC channel 2
- **A3/GPIO29**: ADC channel 3

### Digital Pins

These are the digital I/O pins. They all have multiple capabilities but can be used only one at a time.

- **TX/GPIO0**: The main UART0 TX pin (UART0 TX, I2C0 SDA, PWM0 A).
- **RX/GPIO1**: The main UART0 RX pin (UART0 RX, I2C0 SCL, PWM0 B).
- **SCK/GPIO2**: The main SPI0 SCK pin (SPI0 SCK, I2C1 SDA, PWM1 A).
- **MO/GPIO3**: The main SPI0 MOSI pin (SPI0 TX, I2C1 SCL, PWM1 B).
- **MI/GPIO4**: The main SPI0 MISO pin (SPI0 RX, UART1 TX, I2C0 SDA, PWM2 A).
- **SS/GPIO5**: The main SPI0 CS/SS pin (SPI0 CSn, UART1 RX, I2C0 SCL, PWM2 B).
- **D6/GPIO6**: Digital I/O pin 6 (I2C1 SDA, PWM3 A).
- **D7/GPIO7**: Digital I/O pin 7 (I2C1 SCL, PWM3 B).
- **SDA/GPIO8**: The main I2C0 data pin (I2C0 SDA, UART1 alt TX, PWM4 A).
- **SCL/GPIO9**: The main I2C0 clock pin (I2C0 SCL, UART1 alt RX, PWM4 B).
- **D10/GPIO10**: Digital I/O pin 10 (SPI1 SCK, I2C1 SDA, PWM5 A).
- **D11/GPIO11**: Digital I/O pin 11 (SPI1 TX, I2C1 SCL, PWM5 B).
- **D12/GPIO12**: Digital I/O pin 12 (SPI1 RX, I2C0 SDA, PWM6 A).
- **D13/GPIO13**: Digital I/O pin 13 (SPI1 CSn, I2C0 SCL, PWM6 B).
- **D14/GPIO14**: Digital I/O pin 14 (I2C1 SDA, PWM7 A).
- **D15/GPIO15**: Digital I/O pin 15 (I2C1 SCL, PWM7 B).
- **LED/GPIO16**: On-board Status LED / Digital I/O pin 16 (UART0 TX, SPI0 RX, PWM0 A).
- **A0/GPIO26**: Analog I/O pin 0 (ADC0, I2C1 SDA, PWM5 A).
- **A1/GPIO27**: Analog I/O pin 1 (ADC1, I2C1 SCL, PWM5 B).
- **A2/GPIO28**: Analog I/O pin 2 (ADC2, UART0 TX, PWM6 A).
- **A3/GPIO29**: Analog I/O pin 3 (ADC3, UART0 RX, PWM6 B).
