Introducing **TerraLink A7672S**, a cellular modem board for connecting Glyph development boards and other microcontrollers to the mobile network. Glyph handles your application, sensors, and local controls; the A7672S handles the cellular connection. Together they can support remote monitoring, telemetry, and devices that need connectivity beyond a local Wi-Fi network.

- **Modem**: SIMCom A7672S, from the LTE Cat 1 A7672 family.
- **Cellular Data**: Rated peak speeds of 10 Mbps download and 5 Mbps upload.
- **Dimensions**: 63.50 × 45.72 mm PCB, with 1.6 mm nominal thickness.
- **Host Connections**: USB 2.0 and a seven-pin UART/control header at 2.54 mm pitch.
- **Logic Levels**: 3.3 V on the external UART and GPIO connections, translated to the modem's internal 1.8 V interface.
- **SIM**: Two nano SIM holders connected to the modem's two SIM interfaces.
- **Power**: USB-C input and a separate VIN/GND terminal, with onboard regulation for the modem.
- **Additional Features**: Two translated GPIO connections, local power-key and reset buttons, activity indicators, antenna connectors, and signal test points.

### What the A7672S Does

The modem handles cellular radio communication while the host sends instructions through **AT commands**. These are text commands used to configure the modem, check its status, and request network operations. The modem replies with results and can send notifications when its operating state changes.

The A7672 family supports network services including TCP/IP, MQTT, and HTTP/HTTPS. These let an application exchange messages with an IoT service or send data to a web API using the modem's network stack. SIMCom lists firmware updates over USB and FOTA, which is an update delivered over the cellular network. Features must match the installed firmware. See the [SIMCom A7672 specifications](https://en.simcom.com/product/A7672.html).

The LTE speed figures are modem peak ratings. Actual speed depends on network coverage, signal strength, the operator, the data plan, the remote server, and the host connection. The UART rate is a separate limit and should not be confused with the cellular download rate.

### Connectivity

The board exposes two nano SIM holders. SIM selection and switching are controlled by the modem and its firmware; two holders do not mean two simultaneous cellular data connections. Choose compatible SIMs and follow the installed firmware's SIM-selection procedure.

The cellular antenna connection is separate from the BLE and GNSS antenna connections. BLE and GNSS are optional module features, so verify them against the installed variant and firmware. Check cellular band support against your intended operator before deployment.

USB-C provides computer access for modem communication and supported firmware tools. The UART header provides an embedded-host connection, together with power-key control, reset control, and two translated GPIO signals.

### Using TerraLink with Glyph

Glyph controls TerraLink through its UART interface. Your application runs on Glyph, gathers data, sends commands, and processes modem responses. For example, a Glyph application can read a sensor, upload measurements to a server, and handle connection retries.

The board translates the modem's 1.8 V UART and two GPIO signals to a 3.3 V host interface. Other microcontrollers can use those connections when their logic voltage is compatible. A 5 V host needs appropriate level shifting, and the controller and TerraLink must share ground.

Start with [Programming with Glyph](/documentation/modules/terra/terralink-a7672s/programming) for wiring and an Arduino serial-console example. See [Pinouts](/documentation/modules/terra/terralink-a7672s/pinouts) for the connector functions.

### Development Options

With standard AT firmware, write the controller application in an environment supported by your Glyph board, such as Arduino, ESP-IDF, or MicroPython. A computer can also send AT commands over USB, which is useful for checking modem behavior before implementing the same sequence on Glyph.

Programming Glyph and updating A7672S firmware are separate operations. SIMCom offers embedded development options for some A7672 variants, but direct application development inside this modem requires confirmation of the exact module revision, SDK, and firmware support. Use the vendor tools and a matching image for modem firmware updates.

### Power Supply

Power TerraLink through its supported power input rather than a controller GPIO. Cellular transmission causes bursts of current, so the source must support modem operation without the voltage dropping. The VIN screw terminal is marked for **5–15 V DC**; USB-C uses **5 V**. Choose a supply that can handle cellular current bursts.
