The GM004 Audio Codec Module is a compact I2S audio breakout board built around the NAU8325 stereo Class-D amplifier. It provides a complete audio playback solution for microcontrollers and single-board computers, accepting digital I2S audio data and driving speakers directly without requiring a separate amplifier stage. The board includes an I2C interface for volume control and configuration, making it suitable for portable speakers, voice assistants, and other embedded audio applications.

## Components

- NAU8325 stereo Class-D audio amplifier with integrated DAC
- I2S digital audio input interface (MCLK, BCK, LRCK, DACDAT)
- I2C control interface for volume and configuration (SCL, SDA)
- Differential stereo speaker outputs (SPK_LN, SPK_LP, SPK_RN, SPK_RP)
- Dual power supply inputs (+3V3 for logic, +5V for amplifier)
- Board dimensions: 25.4 × 22.9 mm with 2.5 mm mounting holes

## Pin Configuration

- **SPK_LN** — Left speaker negative output
- **SPK_LP** — Left speaker positive output
- **SPK_RP** — Right speaker positive output
- **SPK_RN** — Right speaker negative output
- **LRCK** — I2S left/right clock (word select)
- **DACDAT** — I2S serial data input
- **BCK** — I2S bit clock
- **MCLK** — Master clock input
- **SCL** — I2C clock line
- **SDA** — I2C data line
- **GND** — Ground reference
- **+3V3** — Logic power supply (3.3 V)
- **+5V** — Amplifier power supply (5 V)

## Amplifier Output Ratings

The NAU8325 amplifier delivers up to 3 W per channel into 4 Ω speakers with a 5 V supply. The differential outputs allow direct connection of speakers without output coupling capacitors. The amplifier supports both stereo (two speakers) and mono bridge-tied load (BTL) configurations. For best performance, use speakers rated between 4 Ω and 8 Ω.

## Working

The module receives digital audio data through the I2S interface. The microcontroller generates the master clock (MCLK), bit clock (BCK), and left/right clock (LRCK) signals, while sending audio samples over the DACDAT line. The NAU8325 decodes this I2S stream, converts it to analog using its internal DAC, and amplifies the signal through the Class-D output stage to drive the connected speakers.

The I2C interface provides register-level control over volume, gain, and operating modes. The +3V3 supply powers the digital logic and I2C interface, while the +5V supply powers the analog amplifier stage. The board includes onboard decoupling capacitors for stable operation.

## Applications

- Portable Bluetooth speakers
- Voice assistant devices
- Audio playback for microcontroller projects
- IoT devices with sound output
- Alarm and notification systems
- DIY music players

## Step 2: Circuit Diagram

Connect the module to your microcontroller as follows:

| Module Pin | Microcontroller Pin |
|------------|---------------------|
| MCLK | I2S master clock output |
| BCK | I2S bit clock output |
| LRCK | I2S word select output |
| DACDAT | I2S data output |
| SCL | I2C clock (SCL) |
| SDA | I2C data (SDA) |
| +3V3 | 3.3 V supply |
| +5V | 5 V supply |
| GND | Common ground |

Connect the left speaker to SPK_LP and SPK_LN, and the right speaker to SPK_RP and SPK_RN. Ensure the power supplies are properly decoupled with 100 µF capacitors near the module if using longer supply wires.

## Step 3: Code Setup

The following Arduino example demonstrates basic audio playback using the ESP32's I2S peripheral. Install the ESP32 board package in Arduino IDE and use this code:

```cpp
#include <driver/i2s.h>
#include <math.h>

#define I2S_BCK_PIN  26
#define I2S_LRCK_PIN 25
#define I2S_DATA_PIN 22
#define I2S_MCLK_PIN 27

#define SAMPLE_RATE 44100
#define SAMPLE_BITS 16

void setup() {
  Serial.begin(115200);

  i2s_config_t i2s_config = {
    .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_TX),
    .sample_rate = SAMPLE_RATE,
    .bits_per_sample = I2S_BITS_PER_SAMPLE_16BIT,
    .channel_format = I2S_CHANNEL_FMT_RIGHT_LEFT,
    .communication_format = I2S_COMM_FORMAT_STAND_I2S,
    .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
    .dma_buf_count = 8,
    .dma_buf_len = 64,
    .use_apll = false,
    .tx_desc_auto_clear = true,
    .fixed_mclk = 0
  };

  i2s_pin_config_t pin_config = {
    .bck_io_num = I2S_BCK_PIN,
    .ws_io_num = I2S_LRCK_PIN,
    .data_out_num = I2S_DATA_PIN,
    .data_in_num = I2S_PIN_NO_CHANGE
  };

  i2s_driver_install(I2S_NUM_0, &i2s_config, 0, NULL);
  i2s_set_pin(I2S_NUM_0, &pin_config);
  i2s_set_clk(I2S_NUM_0, SAMPLE_RATE, SAMPLE_BITS, 2);
}

void loop() {
  // Generate a 440 Hz sine wave
  int16_t samples[128];
  static float phase = 0;
  const float freq = 440.0;
  const float phase_step = 2.0 * M_PI * freq / SAMPLE_RATE;

  for (int i = 0; i < 128; i += 2) {
    int16_t val = (int16_t)(sin(phase) * 8000);
    samples[i] = val;     // Left channel
    samples[i + 1] = val; // Right channel
    phase += phase_step;
    if (phase >= 2.0 * M_PI) phase -= 2.0 * M_PI;
  }

  size_t bytes_written;
  i2s_write(I2S_NUM_0, samples, sizeof(samples), &bytes_written, portMAX_DELAY);
  delay(10);
}
```

## Step 4: Upload the Code

Connect your microcontroller to your computer via USB, select the correct board and port in the Arduino IDE, and upload the sketch. Ensure the module is powered with both 3.3 V and 5 V supplies before uploading.

## Step 5: Observe the Output

After uploading, you should hear a continuous 440 Hz tone from both speakers. If no sound is produced, verify all I2S connections and confirm that both power supplies are present. Adjust the volume by sending I2C commands to the NAU8325's volume control registers (address 0x02 for left channel, 0x03 for right channel).
