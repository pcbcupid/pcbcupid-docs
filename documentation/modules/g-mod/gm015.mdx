The GM015 DC-DC Buck Converter is a compact, board-level step-down power module built around the SY81103 synchronous buck regulator. It converts a higher DC input voltage down to a lower, stable output voltage, making it ideal for powering microcontrollers, sensors, and other logic circuits from batteries, solar panels, or unregulated supplies. The module measures 25.4 × 22.9 mm and includes through-hole pads for easy integration into custom PCBs or breadboard prototyping.

## Components

- **SY81103 synchronous buck regulator IC** — the core switching converter
- **Input capacitor** — polarized electrolytic capacitor for input filtering
- **Output capacitor** — unpolarized ceramic capacitor for output smoothing
- **Inductor** — energy storage element for the buck conversion
- **Status LED** — indicates when the module is powered
- **Screw terminal** — 2-pin connector for input power wiring
- **Four mounting holes** — 2.5 mm drill diameter for securing the module

## Pin Configuration

- **IN (Pin 1)** — Positive DC input voltage (4.5V–18V typical)
- **GND (Pin 2)** — Ground connection for input side
- **OUT (Pin 3)** — Regulated DC output voltage
- **GND (Pin 4)** — Ground connection for output side

## Working

The GM015 uses a synchronous buck (step-down) topology. When input power is applied, the SY81103 switches the internal high-side MOSFET on and off at a high frequency. During the ON phase, current flows through the inductor, storing energy and charging the output capacitor. During the OFF phase, the low-side MOSFET provides a path for the inductor current to continue flowing to the load. The feedback loop continuously adjusts the duty cycle to maintain a stable output voltage regardless of input voltage variations or load changes. The output voltage is preset on the module and is not user-adjustable; check the module labeling for the specific output voltage of your unit.

## Applications

- Powering Arduino and other microcontroller boards
- Supplying sensors and IoT devices from higher-voltage sources
- Battery-powered projects requiring voltage step-down
- Solar panel systems with 12V panels powering 5V logic
- Bench power supply for breadboard prototyping
- Embedded systems requiring efficient power conversion

## Step 1: Hardware Required

- GM015 DC-DC Buck Converter module
- DC power source (e.g., 12V battery or wall adapter) within the module's input range
- Multimeter for measuring output voltage
- Load device (e.g., Arduino board, LED with resistor, or resistor bank)
- Connecting wires or jumper cables

## Step 2: Circuit Diagram

Connect the DC power source to the **IN** and **GND** pins on the input side of the module. Connect your load to the **OUT** and **GND** pins on the output side. Ensure the input voltage is within the module's specified range (typically 4.5V–18V) and that the load current does not exceed the module's maximum rating. Observe correct polarity — reverse polarity can damage the module.

## Step 3: Code Setup

While the GM015 is an analog power module that requires no programming, you can verify its output using an Arduino's analog input. Connect the module's **OUT** pin to an Arduino analog input (e.g., A0) and the module's **GND** to the Arduino's GND. Use the following sketch to read and display the output voltage:

```cpp
const int analogPin = A0;
float voltage = 0.0;

void setup() {
  Serial.begin(9600);
  Serial.println("GM015 Output Voltage Monitor");
}

void loop() {
  int raw = analogRead(analogPin);
  // Assuming 5V reference; adjust if using 3.3V
  voltage = (raw / 1023.0) * 5.0;
  Serial.print("Output Voltage: ");
  Serial.print(voltage, 2);
  Serial.println(" V");
  delay(1000);
}
```

## Step 4: Upload the Code

Connect the Arduino to your computer via USB, select the correct board and port in the Arduino IDE, and upload the sketch. Open the Serial Monitor at 9600 baud to view the voltage readings.

## Step 5: Observe the Output

Apply power to the GM015 module and observe the Serial Monitor output. The displayed voltage should remain stable near the module's rated output voltage. The onboard LED should illuminate, indicating the module is powered. If the voltage reads zero or is unstable, check all connections, verify input polarity, and confirm the input voltage is within the specified range.
